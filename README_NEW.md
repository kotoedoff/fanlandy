# Fanland OSINT Multi-Tool

Мощный OSINT инструмент с GUI на базе PyQt6. Интегрирует лучшие инструменты: Maigret, Holehe, Toutatis.

## Установка

```bash
cd fanland
pip install -r requirements.txt
python gui.py
```

## Возможности

- 🔥 **OSINT Tools** - Maigret (3000+ сайтов), Holehe (email), Toutatis (Instagram)
- 📞 Phone OSINT
- 🌐 IP/Domain анализ
- 📧 Email проверка
- 🔍 Username поиск
- 🛡️ Web Security Tools

## Использование

1. Запустите `python gui.py`
2. Выберите **Information Gathering** → **OSINT Tools**
3. Введите username/email
4. Выберите инструмент
5. Нажмите Start Search
